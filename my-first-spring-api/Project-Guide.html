🛒 SocioMart

Food Marketplace Platform - Project Guide

📋 Project Overview

SocioMart is a food marketplace platform where buyers can order food from multiple kitchen/seller. It has different user roles including Buyers, Sellers, Admins, and Super Admins. The project is built using Spring Boot framework with Java 21.

🏗️ How the System Works

1
Buyer browses kitchens and products on the marketplace
2
Buyer places an order with OTP authentication
3
Seller receives and manages the order
4
Admin approves/rejects sellers
5
Super Admin manages platform settings and features

## 1. Defect Severity Definitions
- **P0 (Critical):** Data corruption, unauthorized privilege escalation, complete flow block, or critical financial/stock discrepancy.
- **P1 (High):** Major business logic defect, broken pre-order cutoff window, broken dashboard layout, or unhandled 4xx/5xx errors in key user flows.
- **P2 (Medium):** Minor functional bugs, responsive UI clipping, theme contrast anomalies, or configuration warnings.
- **P3 (Low):** Minor cosmetic issues, non-blocking telemetry gaps, or informational improvements.
